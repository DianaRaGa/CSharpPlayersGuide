## **2026-08-26** — Variables, Types, and Methods

### What clicked

C# feels more explicit than Python when working with variables.

In Python I can write:

```python
name = "Diana"
```
and Python determines the type.

In C#:
```csharp
string name = "Diana";
```
I explicitly tell C# that name is a string.
